# Circuit-Design

Embedded Systems & IoT 

## Overview

This repository contains the practical assignment work for the Embedded Systems & IoT course. The project involves:

- Electrical circuit calculations
- Circuit schematic design using EasyEDA
- ESP32 microcontroller integration with a DHT22 sensor
- Documentation and exported PDF schematics

---

# Repository Contents

## Part A – Circuit Calculations

This section contains calculations for two electrical circuits:

### Circuit A (Series Circuit)

The following calculations were performed:

- Total resistance
- Total current
- Current through each resistor
- Voltage drop across each resistor
- Power dissipated through each resistor

### Circuit B (Parallel Circuit)

The following calculations were performed:

- Total resistance
- Total current
- Current through each resistor
- Voltage drop across each resistor
- Power dissipated through each resistor

All calculations were documented and exported as PDF files.
